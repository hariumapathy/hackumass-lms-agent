## Submission rules that affect us
1. Registered participants only; **every member needs a Devpost account and must be listed** as a contributor.
2. **Public GitHub repo** link required, and it must stay public after the event (ours: https://github.com/hariumapathy/hackumass-lms-agent).
3. **Live demo required**; a demo video under 3 minutes is optional but recommended.
4. **Document all external code** (libraries, frameworks, open-source) in the submission and **say it during judging**. Our list: [pitch/devpost.md → Credits](pitch/devpost.md#credits-external-code).
5. Only work done during the hacking period; one project per team; max 4 people.
6. Pick **only ONE `[HACKUMASS]` category** on Devpost; grand prizes are automatic; sponsor/MLH prizes are separate opt-ins (unlimited).

## Judging criteria → how we score
| Criterion | Our angle |
|---|---|
| **Innovation** | Cross-platform sync + agent with *verified* citations and change detection, not just a chatbot |
| **Functionality** | Live demo on real (or seeded backup) data; tests per spec; clean UI |
| **Practicality** | Every UMass student has this problem; token + session login (no passwords); path to an official LTI app |
| **Presentation** | Tight 3-minute story ([pitch/pitch.md](pitch/pitch.md)), every teammate speaks |
